# v1.1 — Sites tab split view (iPhone Duo / wide-screen)

**Goal:** On regular-width screens (unfolded iPhone Duo, iPad), the Sites tab shows a
master–detail layout (list + detail side by side). On compact width (folded Duo,
regular iPhone) it behaves exactly as today (tap row → push detail). One adaptive
`NavigationSplitView` covers both; SwiftUI collapses/expands by size class.

**Scope:** Sites tab only. Map (full-bleed, already wide-optimal) and Profile
(settings-style stack) are intentionally left unchanged. Stay on iOS 17. Sidebar-
adaptable `TabView` is deferred to 1.2 (pending iOS 17 adoption data).

**Decided:** approved by owner 2026-11-18.

## Phase 1 — Sites tab → NavigationSplitView
- `SitesListView`: replace the `NavigationStack { List { NavigationLink … } }` with
  `NavigationSplitView { sidebar } detail: { … }`.
- Sidebar = the existing filtered `List`, converted to `List(results, selection:
  $selectedSiteID)` with each row `.tag(site.id)`; drop the per-row `NavigationLink`
  (selection drives navigation). Keep `.searchable`, Sort/Filter toolbar, filter
  sheet, empty-state overlay, and `.navigationTitle("Sites")` on the sidebar.
- New `@State private var selectedSiteID: Site.ID?` (String?).
- Detail = resolve the selected `Site` (look up by id in `results`, falling back to
  `catalogStore.sites` so it survives a filter change); show `SiteDetailView(site:)`,
  else a `ContentUnavailableView("Select a site", …)` placeholder.
- Keep the existing `.onAppear` / `.onChange` / `.task` on the outer container.

## Phase 2 — Version bump
- `project.yml`: `MARKETING_VERSION` 1.0 → 1.1, `CURRENT_PROJECT_VERSION` 1 → 2.
- Regenerate the xcodeproj with the real xcodegen binary
  (`~/bin/xcodegen_dist/bin/xcodegen`, not the symlink).

## Phase 3 — Verify (proportionate)
- Build for the simulator.
- Spot-check at two widths: compact (an iPhone — row tap pushes detail, unchanged)
  and regular (iPad or resized window — list + detail side by side, placeholder
  before selection, selection survives fold↔unfold). No full screenshot tour.

## Out of scope / deferred
- Sidebar-adaptable tabs (`.tabViewStyle(.sidebarAdaptable)`, iOS 18) → 1.2.
- Map and Profile split-view treatments (would not improve those screens).
